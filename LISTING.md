### 🎯 What makes this a bestseller?

**8 Views your users will actually use:**
- 🌀 **Swarm Workflow** — an n8n-style animated DAG showing your orchestrator dispatching agents in real time
- 📋 **Kanban Board** — 5 columns for task management
- 📊 **Gantt Timeline** — see task durations and live progress
- 💬 **Chat Rooms** — per-LLM streaming conversations
- ✨ **Skills Explorer** — 100 skills, searchable and filterable
- 🔌 **MCP Connectors** — 10 built-in Model Context Protocol bridges
- 🖥️ **Endpoints CRUD** — add custom OpenAI/Anthropic-compatible endpoints
- 📄 **Versioned Reports** — every report tagged with LLM model specs

**Production-grade architecture:**
- NextAuth.js authentication with 3 roles (admin / operator / viewer)
- Zod typed schema contracts with two-phase commit
- Circuit-breaker pattern per agent (auto-trips on failure)
- Least-privilege tool scoping
- Shared episodic memory across agents
- Parallel DAG execution with subagent spawning

**6 LLMs included:**
GLM-4-Plus (live demo), DeepSeek-V3, Claude 3.5 Sonnet, GPT-4o, Gemini 1.5 Pro, Qwen2.5-Max

**Deploy anywhere:**
One-click buttons for Railway, Render, and Vercel. Docker Compose for self-hosting. SQLite for dev, swap to PostgreSQL for production.
